# 人が遊んだときの比較

目的は、AI予測表示があると「得点」と「面白さ・自分で考える感覚」がどう変わるかを、まず本人1名で確認すること。
1回の小規模な比較なので、全ユーザーへの効果や因果関係の実証とは扱わない。

## 進め方

プロジェクトのルートで実行する。

```bash
.venv/bin/python src/game.py playtest
```

1. 練習を2ゲーム行う。予測なし・ありを1回ずつ試し、操作を覚える。練習の得点と感想は本番の集計から除く。
2. 本番を4ゲーム行う。すべて3投で、できるだけ高い合計点を狙う。回転・スイープは自由に使える。
3. 毎ゲームの終了後、面白さ、自分で狙い・戦略を考えられたか、操作の分かりやすさを1〜5で回答する。自由記述は任意。
4. 最後に2組の得点差と感想を比較する。所要時間の目安は10〜15分。

本番の前半2ゲームは同じ氷の初期値・変化系列を使い、AI予測の表示あり・なしを切り替える。
後半2ゲームは別の氷で表示の順番を逆にする。順番は開始前にシードから決め、得点を見て条件を選び直さない。
各ゲームで盤面とゲーム中の推定を初期化し、操作の初期値も揃える。予測なしでは予想軌跡・停止位置を表示せず、先読み計算も行わない。
物理・操作・採点は両条件で同じ。内部の氷推定は同じように動かし、推定自体が石の動きを変えることはない。

## 記録・中断・再開

記録は`report/playtests/日時_識別子/`へ保存する。氏名などの入力は不要で、外部へ送信しない。

- `study.json`：開始前に決めた条件、順番、得点、感想、選択時間、エラー、中断した試行。
- `trial_*.json`：各試行の投球指示・スイープ入力・観測・最終配置。既存のリプレイ確認に使用できる。
- `summary.md` / `.json`：練習を除いた比較結果。未完了なら未完了と表示する。

比較中はリトライを無効にする。途中でウィンドウを閉じた場合も試行を残し、再開時はそのゲームを初期状態からやり直す。
3投が終わって感想だけ未回答の場合は、結果を保持して感想入力から再開する。中断があれば結果の解釈時に明記する。

```bash
# DIRECTORYを画面・ターミナルに表示された保存先へ置き換える
.venv/bin/python src/game.py playtest --study DIRECTORY
.venv/bin/python src/game.py playtest-summary --study DIRECTORY
```

コード・学習モデルが途中で変更された場合、異なる版の結果を混ぜないため同じ比較の再開を拒否する。

## 結果の見方

同じ氷の組ごとに「予測あり−なし」の得点差と感想の差を出し、両方の組を報告する。
良い結果の組だけを選ばず、得点が下がった場合、楽しさが変わらない場合、自分で考える感覚が弱まった場合も残す。
5段階の回答は個人の主観で、差の平均だけでなく各回答と自由記述を読む。
選択時間は投球可能になってから投球までの時間。予測待ち・説明を読む時間・離席も含み、感想入力は含めない。

同じ氷を経験した記憶、操作の慣れ、予測への期待の影響は残る。1人・2組の結果で統計的な有意差や一般的な効果を主張しない。
結果を説明資料へ反映する場合も、人数、試行数、順番、中断、条件、本人の感想を添える。

## 自動確認との区別

2026年11月1日に本人1名の比較を実施した。[結果と表示問題の修正](poc_findings.md#人による比較プレイと画面の揺れ修正2026年11月1日)を参照。
この結果は修正前の画面で取得したもの。新たな比較は新しい記録フォルダを使い、前回の回答を上書きしない。

```bash
.venv/bin/python src/game.py playtest-smoke
```

これは6ゲームと感想画面を自動操作する機能確認。回答はダミーで、人の評価には使えない。
`report/playtest_smoke/`へ分けて保存し、集計の`human_evidence`も常にfalseになる。
人のプレイ記録や自由記述はコード配布ZIPへ自動で含めない。
